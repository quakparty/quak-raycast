# Quak API Key

1. Sign in at [quak.party](https://quak.party) and open [Settings → API Keys](https://quak.party/app/settings/keys).
2. Create a key with scope **play** (or **create** if you also want to save plays as clips) and copy it. It begins
   with `qk_key_` and is shown only once.
3. Paste it here.

The key belongs to one workspace: plays use its speakers and defaults.

More workspaces: add a key from each as Second Workspace and Third Workspace, then switch in the commands' dropdown.
